# Fonts

Inter, by Rasmus Andersson and the Inter project authors (https://rsms.me/inter/), under the SIL Open
Font License 1.1; see `OFL.txt`. These are static instances of the variable font, at an optical size
of 14, made with fontTools:

    fonttools varLib.instancer InterVariable.ttf wght=400 opsz=14 --update-name-table -o Inter-Regular.ttf
